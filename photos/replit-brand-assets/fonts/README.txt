Replit Brand Fonts — ABC Diatype Plus Variable
==============================================

Files in this folder:
  diatype-variable.woff2          Web fallback (variable, weight axis 100–900)
  diatype-variable.ttf            TrueType fallback (variable, weight axis 100–900)
  diatype-semi-mono.woff2         Same binary as diatype-variable.woff2, served
                                  under the 'ABC Diatype Semi-Mono' @font-face
                                  family. Dinamo ships Semi-Mono inside the
                                  Plus Variable file via the MONO axis at 0.5
                                  — pinned by .text-eyebrow-* utilities.
  diatype-semi-mono.ttf           TrueType counterpart of the above.
  ABCDiatypePlusVariable.otf      Desktop / print master

Swapping in a different copy
----------------------------
If you have a fully licensed copy of Diatype with different filenames,
overwrite the three files above (keeping the same names), or update the
@font-face references in /artifacts/brand/src/index.css and the download
buttons in /artifacts/brand/src/pages/Home.tsx to match.
